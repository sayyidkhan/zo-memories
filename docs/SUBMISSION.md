## One Sentence About It

Zo Moments turns shared photos, videos, and voice notes into collaborative, editable storybooks and social-ready carousels or videos for couples, families, and friends: https://github.com/sayyidkhan/zo-memories

## How Did You Use Zo?

I built and deployed the full application on Zo Computer: a React frontend and Hono API run as a Zo process service, private media and metadata live on Zo's persistent server storage, and optional GPT-5.6 Luna story drafting is powered through Zo's `/zo/ask` API.
